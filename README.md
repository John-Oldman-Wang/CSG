# CSG

个人 A 股投研系统。

## 这是什么

一套辅助个人价值投资决策的工具，覆盖数据、筛选、分析、监控、提醒、复盘六个环节。

**它做什么**：把事实整理好递到你面前 —— 财务指标、行业横比、估值读数、假设是否被证伪、
组合风险敞口、你自己的交易纪律统计。

**它不做什么**：不预测股价，不做宏观择时，不推荐买入，不自动下单。
判断由人做，系统负责保证判断所需的材料齐全、及时，并且事后能被检验。

## 方法论定位

混合派：**股价下跌 → 寻找原因 → 判断情绪面还是价值面 → 面向未来思考。**

价格下跌本身不构成买卖信号，它触发一个待办复核任务。系统聚合当初的买入假设、
逐条证伪条件的当前状态、超额跌幅拆分、期间发生的事件，然后要求给出结构化结论
（情绪面 / 价值面 / 信息不足）。

复核界面默认隐藏持仓成本与浮盈浮亏，并强制回答一个问题：

> 以今天的价格、今天掌握的信息，我会重新买入这只股票吗？
