# ai — AI 辅助研究

## 做什么

AI 在本系统中是**信息处理器与质疑者**，不是决策者。

```
contract.py   输出契约（schema 层面禁止结论）
analyst.py    上下文组装 + 调用 + 契约校验 + 飞书渲染
```

## 怎么做

### 靠结构约束，不靠提示词

输出 schema 中**不存在** `verdict` / `recommendation` / `conclusion` / `rating`
等字段，且 `additionalProperties: false`。模型即使想给结论也无处安放。

提示词会被绕过、遗忘、在多轮对话中漂移；结构不会。

### 五个部分

```
facts                事实      每条必须注明来源，不含推断
falsification_check  核对      逐条比对已写下的证伪条件；
                              无法用数据判定的一律标 needs_human，不许猜
counter_arguments    反方      攻击用户自己的买入理由。不允许为空
knowledge_gaps       缺口      诚实标出答不上来的部分。不允许为空
questions_for_you    待答      判断权保留在人这里
```

**反方论证是 AI 在此链路的最高价值项**：人天然寻找支持自己的证据，
这是最难自我纠正的偏误，让 AI 扮演对手方比让它当顾问有用得多。

**认知缺口不允许为空**：一份好的分析产出，价值在于诚实说出
「这些你还不知道」，而非把不知道的部分用漂亮话填满。

### 数字永远不经过 LLM

财务数字走数据库，LLM 只处理文本。**没有例外。**
让模型「读」财报读出净利润是灾难——它会在你完全看不出来的地方
编一个数，且格式完美、位数合理，这类错误无法通过检查输出发现。

### strict 模式下越界即拒绝

契约校验失败直接抛错，不降级放行。一旦允许越界结果流向飞书，
用户就会开始接收 AI 的结论——**宁可这条提醒发不出去。**

## 核心陷阱

AI 综合公开信息 = **逼近市场共识**，而共识已经反映在价格里。
超额收益来自「与共识偏离且你是对的」，一个系统性逼近共识的工具
帮不到你，还会制造「我做了深度研究」的错觉。
