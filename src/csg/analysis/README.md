# analysis — 分析层

## 做什么

把原始财报转换成可比较的指标，并按规则标出异常。**只算事实，不下结论。**

```
metrics.py   累计值还原单季 → TTM → 派生比率
flags.py     六条财务红旗规则
```

## 怎么做

### A 股财报是累计口径，必须先还原

Q3 报表的「营业收入」是**前三季合计**，不是第三季单季。直接拿累计值算
同比会得到无意义的结果。

```
Q1单季 = Q1累计
Q2单季 = H1累计 − Q1累计
Q3单季 = Q3累计 − H1累计
Q4单季 = 年报   − Q3累计
```

仅在同一年度内相减；缺失中间期时该季标记 NA，**不做插值**——
凭空补出来的数字比缺失更危险。

TTM = 最近四个单季之和，不足四季返回 NA，不做年化外推
（用两个季度年化推全年，在周期行业里会严重误导）。

### 红旗规则的定位

规则不下「这家公司有问题」的结论，只指出「这个数字不寻常，你需要去看」。
每条输出命中标记 + 触发时的实际数值，后者用于阈值调优与人工解释。

因为在 PIT 面板上计算，可回溯到历史任一时点，回答
**「在 T 时刻我能否发现问题」**——这正是验证① 的核心问题。

## 实测结论（验证①，2026-08-16）

```
覆盖率      58.7%（143 起可评估暴雷中命中 84 起）
提前预警    中位 730 天、均值 603 天  ← 信号有实质内容，非马后炮
误报率      81.0%–98.1%（四个时点）  ← 阈值过松，尚不可直接用作排除条件
```

`cfo_divergence` 触发 223 次、接近其他规则两倍，说明阈值 0.5 偏松——
A 股扩张期公司普遍出现现金流与利润背离。阈值待敏感性分析后调整。
