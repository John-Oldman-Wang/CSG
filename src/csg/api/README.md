# api — HTTP 接口层

## 做什么

把 csg 已有能力暴露成 HTTP。**唯一职责就是暴露，不重新实现任何金融逻辑。**

## 怎么做

PIT 查询、累计值还原、TTM、红旗规则全部复用 csg 模块。
`disclosure_date` 过滤这类要害若在此处或前端重写一遍，
等于埋下第二套 bug——而这类 bug 是静默的，不报错，
只让数字悄悄变得好看。

### 端点分组

```
/api/health          数据水位（陈旧 = 调度已静默失效）
/api/pool            L1 股票池
/api/stocks/{code}   基本信息 / 概览 / 行情 / PIT财务 / 研报
/api/reports         研报检索（时间/标题/机构/股票/行业/评级变化 + 分页）
/api/reports/{id}/analysis   研报分析聚合（一次请求拿全上下文）
/api/events          事件流
/api/tasks           复核任务 + 提交结论
/api/validations     验证运行记录与结果
```

### DuckDB 单写锁的处理

采集运行期间**连只读连接都建不了**。这是选型代价，不是可绕过的实现细节。
此时返回 **503 + 中文说明**，前端识别为 `DataLockedError` 显示「数据更新中」
且不重试——而不是抛一个看不懂的 IOException。

### 缺失与零是两回事

估值等字段缺失时返回 `null` 而非 `0`，前端显示「—」。
显示 0 会让人误读为「市盈率为零」。

## 设计约束

**接口不返回任何形式的买卖建议。** 任何端点如果开始输出「建议买入」，
说明它越界了——判断归人（见 METHODOLOGY 原则 1）。
